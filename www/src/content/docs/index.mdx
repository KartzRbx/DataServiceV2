## Architecture

<pre class="mermaid">
flowchart TB
  subgraph server [Server]
    CS[CreateStore]
    PS[ProfileStore]
    ODS[OrderedDataStore leaderboards]
    CS --> PS
    CS --> ODS
  end
  subgraph client [Client]
    CR[ClientRegistry mirrors]
    UI[UI controllers]
    CR --> UI
  end
  CS -->|QuickNet| CR
</pre>

**Wally:** `kartzrbx/dataservicev2@3.2.0` (KeepData). Bundled `signal`, `quicknet`, and `janitor` — no extra deps in your game.

## Common APIs

| Task | API |
| --- | --- |
| Load player | `PlayerStore:WaitFor(player)` |
| Add coins | `handle:Update(Paths.Currencies.Coins, fn)` |
| Backpack UI | `data:GetChangedSignal(Paths.Inventory.Items)` |
| Top 100 board | `PlayerStore:CreateLeaderboard({ ... })` |
| Studio without API | `UseMock = true` on store options |
