## How it fits in your game

<pre class="mermaid">
flowchart LR
  template["Data template module"] --> init["Server Init"]
  init --> store["ProfileStore"]
  store --> data["Data handle"]
  data --> paths["Paths.Get / Set"]
  paths --> net["QuickNet replicate"]
  net --> client["Client mirror"]
</pre>

Install with Wally: `kartzrbx/dataservicev2`. Bundled `signal`, `quicknet`, and `janitor` ship inside the package — no extra deps in your game's `wally.toml`.

## Quick accessors

| You write | You mean |
| --- | --- |
| `DataServiceServer:WaitFor(player)` | Block until profile is loaded |
| `data:Get(Paths.Currencies.Coins)` | Read merged value (persisted + transient) |
| `data:Set(Paths.Currencies.Coins, 100)` | Write and replicate (server) |
| `data:GetChangedSignal(Paths.Stats.Level)` | React to a path change |
| `data:GetOrderedList(Paths.Inventory, Enum.OrderList.Desc)` | Sorted list query |
